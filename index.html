01 / SCOPE

무엇을 확인했나요?

기존 집계에서 확인한 대상명과 공개 웹사이트를 대조하고, 실제 브라우저 화면 및 표시된 문구를 기록했습니다. 오늘 표본은 비로그인 데스크톱 화면입니다.

홈페이지·브랜드 스토어·리뷰 카테고리 등 선택한 URL만 확인했으며, 해당 매체의 전체 광고 인벤토리를 수집한 것은 아닙니다.

회사명과 소비자 서비스명 연결은 이름 기반 매핑입니다. CJ 계정 ID와 법인·도메인 소유 관계는 원본 퍼블리셔 디렉터리로 보완해야 합니다.

02 / US VALIDATION

미국 지면 ≠ 미국 IP 검증

영문·미국 도메인·USD·지역 선택은 시장 단서입니다. IP 국가를 대신하지 않습니다. 오늘 캡처는 US IP 미검증으로 표시했습니다.

CouponFollow의 Samsung 지면에는 € 혜택이 섞여 있어 미국 적용 요율 비교에서 제외했습니다. 국가 판정에 실패한 일별 실행 역시 미검증으로 남깁니다.

03 / DAILY OPERATIONS

일별 기록을 쌓는 방법

GitHub Actions에 매일 22:00 UTC / 다음날 07:00 KST 수집을 설정했습니다.

날짜는 KST 기준으로 보관하고 각 캡처에는 UTC 시각과 미국 동부 기준 날짜를 함께 저장합니다. 매 실행은 새 브라우저·en-US·뉴욕 시간대를 사용하며, 국가 확인 결과도 기록합니다.

이전 성공 캡처를 덮어쓰지 않습니다. 실패·접속 차단·쿠키 배너도 기록하며, 자동 추출한 브랜드 언급은 검토 대기로 구분합니다. 본문 해시 변화는 광고 변경으로 단정하지 않습니다.

04 / INTERPRETATION

숫자의 의미와 한계

‘캡처’는 이미지 파일이 저장됐다는 뜻입니다. 로그인 입구·보안 확인·빈 화면은 정상적인 경쟁사 지면으로 세지 않습니다. 요율·가격은 수집 시점의 표시값이며 거래 적용을 보장하지 않습니다.

편집기사·리뷰·쿠폰·캐시백을 구분합니다. 브랜드 언급량은 노출 점유율, 광고 집행량, 매출 또는 유료 게재 증거가 아닙니다.

공개 샘플에는 내부 매출·커미션·고객 거래정보를 포함하지 않습니다. 과거 캡처 데이터가 없으므로 첫날의 증감률은 표시하지 않습니다.
